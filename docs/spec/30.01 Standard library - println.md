# What does `println()` do?

`core::println(value)` accepts one `any` argument at the native boundary.
The runtime accepts strings and booleans, writes their display text, and appends
one newline. The call returns unit and contributes the `write_stdout` effect.
See [core lookup](./25.03%20Modules%20-%20Core%20module.md) for unqualified calls.

## Example: `println()` writes one line

main.ocelot-script:

```ocelot
println("ocelot");
```

### Output

```text
ocelot
```

## Example: `bool` arguments print as source-style literals

main.ocelot-script:

```ocelot
println(true);
println(false);
```

### Output

```text
true
false
```

# What happens when an argument is missing?

Argument counts are checked before execution, as for other
[function calls](./02.01%20Expressions%20-%20Function%20calls.md).

## Example: `println()` requires exactly one argument

main.ocelot-script:

```ocelot
println();
```

### Error

```text
error: type error: `println` expects exactly one argument
  ╭▸ main.ocelot-script:1:1
  │
1 │ println();
  ╰╴━━━━━━━ missing argument
at main.ocelot-script:1:1
```
