# What is `println()`?

`println()` writes one line of text to standard output.
It is the simplest way for a program to produce visible output.
It is declared as `core::println`, and the `core` module is available as a fallback in every file.

# What rules should readers assume first?

For the first version of the spec:

- `println()` is called like a normal function
- it is declared in the compiler-provided `core` module
- it accepts exactly one `any` argument at the native boundary
- current runtime values accepted by that boundary are `string` and `bool`
- it writes that value to standard output
- it appends a trailing newline automatically
- it contributes the `write_stdout` effect declared by `core`

This intentionally keeps the first output model narrow.
Formatting placeholders, interpolation, multiple arguments, and richer I/O APIs can come later.

# What does a successful call look like?

## Example: `println()` writes one line

main.ocelot-script:

```ocelot
println("ocelot");
```

### Output

```text
ocelot
```

## Example: each call writes its own line

main.ocelot-script:

```ocelot
println("alpha");
println("beta");
```

### Output

```text
alpha
beta
```

## Example: `bool` arguments print as source-style literals

main.ocelot-script:

```ocelot
println(true);
println(false);
```

### Output

```text
true
false
```

## Example: template strings interpolate before printing

main.ocelot-script:

```ocelot
fun greet(name: string) {
    println("Hello ${name}!");
}

greet("Ada");
```

### Output

```text
Hello Ada!
```

# What happens when `println()` is used incorrectly?

The first version should reject calls that do not match the required one-argument string-or-`bool` form.

## Example: `println()` requires exactly one argument

main.ocelot-script:

```ocelot
println();
```

### Error

```text
error: type error: `println` expects exactly one argument
  ╭▸ main.ocelot-script:1:1
  │
1 │ println();
  ╰╴━━━━━━━ missing argument
at main.ocelot-script:1:1
```
