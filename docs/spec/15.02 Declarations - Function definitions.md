# How are functions declared?

User-defined functions use `fun name(param: type, ...) { ... }`. The parameter list
is required but may be empty. Each parameter has a unique name and a `string` or
`bool` type; the body contains zero or more statements. Function names are unique
within a module. Declarations may coexist with tests and, in scripts, top-level statements.

Native declarations use `native fun name(param: type, ...);`. They have no body,
are reserved for `core`, and may additionally use [any](./10.02%20Types%20-%20Any.md) parameters.

# What does a parameterized function definition look like?

Parameters become immutable local bindings inside the function body.
See [function calls](./02.01%20Expressions%20-%20Function%20calls.md) for argument counts, types, and unit results.

## Example: a function can declare typed parameters

main.ocelot-script:

```ocelot
fun greet(name: string, excited: bool) {
    println(name);
    assert(excited);
}

greet("hello", true);
```

### Output

```text
hello
```

# What does the smallest function definition look like?

The smallest function definition has a name and an empty body.

## Example: a file can declare one function

main.ocelot-script:

```ocelot
fun greet() {}
```

### Output

```text
```

# Where are native functions and effects specified?

Native implementations are supplied by the compiler through
[core](./25.03%20Modules%20-%20Core%20module.md).
Effect clauses follow the parameter list; see [effects](./27.01%20Effects%20-%20Nominal%20effect%20declarations.md) for their meaning.
See [file execution](./28.01%20Runtime%20behavior%20-%20Scripts.md) for the special role of a module's `main()`.

# Can a call resolve a later function definition?

Yes. Functions can call other functions declared later in the same module.

## Example: a call can target a function declared later in the file

main.ocelot-script:

```ocelot
greet();

fun greet() {
    println("hello");
}
```

### Output

```text
hello
```

# What happens when two functions share the same name?

Function names must be unique within the same module.

## Example: duplicate function names are a resolver error

main.ocelot-script:

```ocelot
fun greet() {}
fun greet() {}
```

### Error

```text
error: duplicate function `greet`
  ╭▸ main.ocelot-script:2:5
  │
2 │ fun greet() {}
  │     ━━━━━ duplicate function
  │
  ⸬  main.ocelot-script:1:5
  │
1 │ fun greet() {}
  ╰╴    ━━━━━ already defined here
at main.ocelot-script:2:5
```

# What happens when two parameters share the same name?

Parameter names must be unique within one function declaration.

## Example: duplicate parameter names are a resolver error

main.ocelot-script:

```ocelot
fun greet(name: string, name: bool) {}
```

### Error

```text
error: duplicate parameter `name`
  ╭▸ main.ocelot-script:1:25
  │
1 │ fun greet(name: string, name: bool) {}
  │                         ━━━━ duplicate parameter
  │
  ⸬  main.ocelot-script:1:11
  │
1 │ fun greet(name: string, name: bool) {}
  ╰╴          ━━━━ already defined here
at main.ocelot-script:1:25
```
