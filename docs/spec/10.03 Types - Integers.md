# What values have type `int`?

`int` is a signed 64-bit integer ranging from -9223372036854775808 through
9223372036854775807. Decimal digits form literals; leading zeros remain decimal.
There are no floats, alternate bases, separators, suffixes, or implicit conversions.
Unary `-` is an operator. The direct spelling `-9223372036854775808` is valid;
the positive magnitude `9223372036854775808` is rejected, even inside parentheses.

Use `int` in bindings, parameters, and return annotations. Display, interpolation,
assertion diffs, and eval results use exact decimal text without quotes.
See [integer operations](<02.09 Expressions - Integer operations.md>) for checked
arithmetic, ordering, and effects.

## Example: integer values retain their type through calls and bindings

main.ocelot-script:

```ocelot
fun identity(value: int) -> int {
    value
}

let min: int = -9223372036854775808;
let max = identity(value: 9223372036854775807);
println(min);
println(max);
println(42);
println("${min}:${max}");
assert_eq(expected: 42, actual: identity(value: 42));
assert_eq(expected: min, actual: -9223372036854775808);
assert(42 == 42);
assert(42 != 43);
```

### Output

```text
-9223372036854775808
9223372036854775807
42
-9223372036854775808:9223372036854775807
```
