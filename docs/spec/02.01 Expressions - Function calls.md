# What is a function call expression?

A function call expression invokes a callable name using parentheses.
The arguments appear in source order inside the parentheses.

In the first version of the language:

- the callee is an identifier or `::`-qualified identifier path
- arguments are separated by commas
- a call expression can be used as an expression statement
- the caller must supply exactly the number of arguments declared by the callee
- each argument must match the callee's declared parameter type

# What does a call expression look like?

## Example: a call expression can be used as a statement

main.ocelot-script:

```ocelot
println("hello");
```

### Output

```text
hello
```

## Example: a call expression can pass typed arguments to a user-defined function

main.ocelot-script:

```ocelot
fun greet(name: string) {
    println(name);
}

greet("hello");
```

### Output

```text
hello
```

# What happens when a call names no known function?

The resolver should reject calls whose callee name does not exist in the program environment.

## Example: calling an unknown function is a resolver error

main.ocelot-script:

```ocelot
printline("hello");
```

### Error

```text
error: unknown function `printline`
  ╭▸ main.ocelot-script:1:1
  │
1 │ printline("hello");
  ╰╴━━━━━━━━━ unknown function
at main.ocelot-script:1:1
```

# What happens when a call uses the wrong argument type?

The resolver should reject call arguments whose types do not match the callee signature.

## Example: user-defined calls reject wrong argument types

main.ocelot-script:

```ocelot
fun greet(excited: bool) {}

greet("hello");
```

### Error

```text
error: type error: argument 1 to `greet` must be bool
  ╭▸ main.ocelot-script:3:7
  │
3 │ greet("hello");
  ╰╴      ━━━━━━━ expected bool
at main.ocelot-script:3:7
```
