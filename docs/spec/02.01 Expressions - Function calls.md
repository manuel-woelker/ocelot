# What is a function call expression?

A function call expression invokes a callable name using parentheses.
The arguments appear in source order inside the parentheses.

In the first version of the language:

- the callee is an identifier or `::`-qualified identifier path
- arguments are separated by commas
- a call expression can be used as an expression statement

# What does a call expression look like?

## Example: a call expression can be used as a statement

main.ocelot:

```ocelot
println("hello");
```

### Output

```text
hello
```

# What happens when a call names no known function?

The resolver should reject calls whose callee name does not exist in the program environment.

## Example: calling an unknown function is a resolver error

main.ocelot:

```ocelot
printline("hello");
```

### Error

```text
error: unknown function `printline`
  ╭▸ main.ocelot:1:1
  │
1 │ printline("hello");
  ╰╴━━━━━━━━━ unknown function
at main.ocelot:1:1
```
