# How are tests declared and executed?

A test declaration has the form `test "name" { ... }`. Its name is a plain string
literal; interpolation is not allowed. The body contains zero or more statements.
Tests may coexist with functions and, in scripts, top-level statements.

`ocelot test` discovers and runs tests. Normal file execution skips test bodies.
The examples below demonstrate normal script execution; test-runner selection and
failure reporting are covered by CLI and engine tests.

# What happens when a file contains only tests?

Executing a test-only script produces no output.

## Example: test-only files are inert during script execution

main.ocelot-script:

```ocelot
test "prints one line" {
    println("hello");
}
```

### Output

```text
```

# What happens when tests and script statements are mixed?

Only the top-level statements run, in source order.

## Example: mixed files skip test bodies during script execution

main.ocelot-script:

```ocelot
println("before");

test "would print during testing" {
    println("inside test");
}

println("after");
```

### Output

```text
before
after
```
