# What is `assert()`?

`assert()` checks that one boolean condition is true.
It is the smallest assertion builtin in `ocelot`.

# What rules should readers assume first?

For the first version of the spec:

- `assert()` is called like a normal function
- it accepts exactly one boolean argument
- `assert(true)` succeeds
- `assert(false)` fails with an assertion error
- `assert()` does not take a custom message yet

This keeps the first assertion API narrow and direct.

# What does a successful call look like?

## Example: `assert(true)` succeeds

main.ocelot-script:

```ocelot
assert(true);
println("after");
```

### Output

```text
after
```

# What happens when the condition is false?

`assert(false)` must fail execution with an assertion error.
Unlike `assert_eq`, this error should stay minimal and should not include an expected/actual diff block.

## Example: `assert(false)` fails

main.ocelot-script:

```ocelot
assert(false);
```

### Error

```text
error: assert condition was false
  ╭▸ main.ocelot-script:1
  │
1 │ assert(false);
  ╰╴━━━━━━━━━━━━━ assertion failed here
at main.ocelot-script:1:1
```

# What happens when the argument is not a boolean?

`assert()` should reject non-boolean arguments.
In the current implementation this surfaces as a resolver error before execution starts.

## Example: `assert()` rejects string literals

main.ocelot-script:

```ocelot
assert("hello");
```

### Error

```text
error: type error: `assert` expects a boolean argument
  ╭▸ main.ocelot-script:1:8
  │
1 │ assert("hello");
  ╰╴       ━━━━━━━ expected boolean
at main.ocelot-script:1:8
```
