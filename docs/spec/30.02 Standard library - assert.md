# What does `assert()` do?

`core::assert` declares `positional condition: bool` and accepts no custom message.
Both `assert(true)` and `assert(condition: true)` are accepted.
A true condition returns unit; a false condition stops execution with an assertion
error. The call contributes the `panic` effect. See [core lookup](./25.03%20Modules%20-%20Core%20module.md) for
unqualified calls.

## Example: `assert(true)` succeeds

main.ocelot-script:

```ocelot
assert(true);
println("after");
```

### Output

```text
after
```

# What happens when the condition is false?

A false condition reports an assertion error without an expected/actual diff.

## Example: `assert(false)` fails

main.ocelot-script:

```ocelot
assert(false);
```

### Error

```text
error: assert condition was false
  ╭▸ main.ocelot-script:1
  │
1 │ assert(false);
  ╰╴━━━━━━━━━━━━━ assertion failed here
at main.ocelot-script:1:1
```

# What happens when the argument is not a `bool`?

Non-`bool` arguments are rejected during resolution, before execution.

## Example: `assert()` rejects string literals

main.ocelot-script:

```ocelot
assert("hello");
```

### Error

```text
error: type error: `assert` expects a bool argument
  ╭▸ main.ocelot-script:1:8
  │
1 │ assert("hello");
  ╰╴       ━━━━━━━ expected bool
at main.ocelot-script:1:8
```
