# Where can comments appear?

Comments are ignored during execution. `//` starts a line comment ending at the
next newline or end of file. `/* ... */` delimits a block comment; block comments nest.

Comments may precede top-level items and statements in block bodies, or follow
an item or statement on the same line. They are not supported inside expressions
or other interior token positions. Comment markers in strings are ordinary text.

## Example: comments can appear around statements

main.ocelot-script:

```ocelot
// greet the user
println("hello"); // visible side effect
```

### Output

```text
hello
```

# How do block comments nest?

Every opening `/*` must have a matching `*/`, including those inside another block comment.

## Example: nested block comments are ignored

main.ocelot-script:

```ocelot
/* outer comment
   /* nested detail */
*/
println("hello");
```

### Output

```text
hello
```

# What happens when a block comment is not closed?

Reaching end of file with an open block comment is a lexer error.

## Example: unterminated block comments are rejected

main.ocelot-script:

```ocelot
println(/* hello
```

### Error

```text
error: unterminated block comment
  ╭▸ main.ocelot-script:1:9
  │
1 │ println(/* hello
  ╰╴        ━━━━━━━━ block comment is missing a closing `*/`
at main.ocelot-script:1:9
```
