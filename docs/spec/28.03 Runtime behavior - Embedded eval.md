# How does embedded evaluation work?

An embedded engine is a persistent host-managed session rooted at a `base_path`.

- `execute` applies a snippet and retains its declarations after successful execution.
- `eval` evaluates exactly one expression and returns its value without retaining its source.
- `eval` rejects declarations and multiple statements before running effects.
- `.ocelot` modules are loaded from the configured `base_path`.
- Failed calls leave the last valid source intact. This does not undo effects already performed.

# How are returned values displayed?

Eval results render as `true` or `false` for booleans, quoted text for strings,
and `()` for unit. Calls return their declared result; an ordinary final expression
statement does not implicitly return its value. Printed output is separate from the
returned value; an `Eval result` expectation checks only the returned value.

## Example: boolean eval returns `true`

eval:

```ocelot
not false
```

### Eval result

```text
true
```

## Example: string eval results stay quoted

eval:

```ocelot
"hello"
```

### Eval result

```text
"hello"
```

## Example: calling `println` returns unit

eval:

```ocelot
println("hello")
```

### Eval result

```text
()
```

# How are definitions retained across calls?

Successful `execute` calls extend the session. Later calls can use those definitions.

## Example: later eval can call a function declared in an earlier execute step

execute:

```ocelot
fun greet() {
    "hello";
}
```

eval:

```ocelot
greet()
```

### Eval result

```text
()
```

# How are helper modules loaded?

Filename-labeled blocks provide modules under `base_path`.

## Example: embedded eval can call a helper module loaded from `base_path`

helper.ocelot:

```ocelot
fun greet() {
    println("hello");
}
```

execute:

```ocelot
fun local() {
    helper::greet();
}
```

eval:

```ocelot
local()
```

### Eval result

```text
()
```

# How are failures reported?

Compilation and execution failures return errors without committing the failed source.

## Example: unresolved modules still fail during embedded eval

eval:

```ocelot
helper::greet()
```

### Error

```text
error: unknown module `helper`
  ╭▸ <embedded>:1:1
  │
1 │ helper::greet();
  ╰╴━━━━━━━━━━━━━ unknown module
at <embedded>:1:1
```

## Example: unresolved identifiers still surface as errors during eval

eval:

```ocelot
missing_value
```

### Error

```text
error: unresolved identifier `missing_value`
  ╭▸ <embedded>:1:1
  │
1 │ missing_value;
  ╰╴━━━━━━━━━━━━━ not found

```
