# What is embedded eval?

Embedded eval executes Ocelot code through a persistent host-managed session instead of by running one entry file directly.
The host creates an embedded engine rooted at one `base_path`, then applies `execute` and `eval` calls against that session.

# What rules should readers assume first?

For the first version of embedded eval:

- the embedded engine keeps one persistent session across calls
- `execute` applies one source snippet to that session
- `eval` evaluates one expression against the current session and returns one runtime value
- later calls can see declarations introduced by earlier successful `execute` calls
- modules are loaded relative to the embedded engine's configured `base_path`
- failed `execute` and `eval` calls do not commit broken source into the persistent session

# How does embedded eval retain earlier definitions?

Successful `execute` calls extend the embedded session.
Later `eval` calls run against that updated session, so they can use functions declared earlier.

## Example: later eval can call a function declared in an earlier execute step

execute:

```ocelot
fun greet() {
    "hello";
}
```

eval:

```ocelot
greet()
```

### Eval result

```text
()
```

# How does embedded eval load modules from `base_path`?

Embedded eval uses the configured `base_path` as its project root for loading `.ocelot` modules.
That means embedded code can import or call helper modules that live on disk under that root.

## Example: embedded eval can call a helper module loaded from `base_path`

helper.ocelot:

```ocelot
fun greet() {
    println("hello");
}
```

execute:

```ocelot
fun local() {
    helper::greet();
}
```

eval:

```ocelot
local()
```

### Eval result

```text
()
```

# What happens when one embedded eval step fails?

Failed embedded eval steps report an error and leave the last valid session intact.
The failed source is not committed as part of the persistent session.

## Example: unresolved modules still fail during embedded eval

eval:

```ocelot
helper::greet()
```

### Error

```text
error: unknown module `helper`
  ╭▸ <embedded>:1:1
  │
1 │ helper::greet();
  ╰╴━━━━━━━━━━━━━ unknown module
at <embedded>:1:1
```
