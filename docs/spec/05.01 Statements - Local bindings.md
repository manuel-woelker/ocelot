# How are immutable local values declared?

Write `let name = expression;` to infer a binding's type, or add an explicit
`string`, `bool`, or `()` annotation after the name. An initializer and terminating
semicolon are required. The initializer runs exactly once; the binding statement
produces unit. `let` is reserved. Reassignment, uninitialized bindings, and
destructuring are not supported.

## Example: inferred and annotated bindings hold expression results

main.ocelot-script:

```ocelot
let enabled: bool = true;
let greeting: string = if enabled {
    "hello"
} else {
    "goodbye"
};
let saved = {
    println("initialized once");
    greeting
};
println(saved);
println(saved);
let done: () = {};
assert_eq(expected: {}, actual: done);
```

### Output

```text
initialized once
hello
hello
```

# Where is a binding visible?

A binding becomes visible after its initializer. Blocks create nested scopes;
an inner binding may shadow an outer one, and its initializer can still read the
outer binding. Leaving a scope restores outer names, including after returns or
runtime errors. Branch bindings do not escape their blocks.

Duplicate names in one scope are errors. Function parameters share the function
body's scope, so they cannot be redeclared directly in that body. Functions and
tests have isolated scopes and cannot capture script-level bindings. Each test
starts with fresh values. Bindings are values rather than callable functions;
shadowing a function name prevents unqualified calls, while qualified calls remain
available.

## Example: inner initializers see outer values and shadowing stays local

main.ocelot-script:

```ocelot
let name = "outer";
{
    let name = "${name} inner";
    println(name);
};
if true {
    let name = "branch";
    println(name);
};
println(name);
```

### Output

```text
outer inner
branch
outer
```

# What happens when an initializer returns?

An explicit return inside an initializer exits the enclosing function before
inserting the binding or running later statements. A non-fallthrough initializer
is compatible with any allowed annotation, following
[block return rules](<02.04 Expressions - Blocks.md>).

## Example: returning from an initializer exits the function

main.ocelot-script:

```ocelot
fun early() -> string {
    let missing: bool = {
        return "early";
    };
    println("unreachable");
}

println(early());
```

### Output

```text
early
```

# How long do script and embedded bindings live?

Script bindings live for that execution. Successful embedded `execute` calls retain
top-level values for later calls without replaying initializers. Failed calls commit
neither new source nor new bindings; previously performed effects remain observable.
See [embedded evaluation](<28.03 Runtime behavior - Embedded eval.md>).

## Example: successive submissions retain values

execute:

```ocelot
let name = "Ada";
```

execute:

```ocelot
let greeting = "Hello ${name}!";
```

eval:

```ocelot
greeting
```

### Eval result

```text
"Hello Ada!"
```

# How are invalid bindings reported?

Names are checked in declaration order, annotations must match initializer types,
and duplicate declarations in the current scope are rejected before execution.

## Example: duplicate bindings are rejected

main.ocelot-script:

```ocelot
let name = "first";
let name = "second";
```

### Error

```text
error: duplicate binding `name`
  ╭▸ main.ocelot-script:2:5
  │
2 │ let name = "second";
  ╰╴    ━━━━ already declared in this scope
at main.ocelot-script:2:5
```

## Example: annotations must match initializer types

main.ocelot-script:

```ocelot
let enabled: bool = "yes";
```

### Error

```text
error: binding type mismatch: expected bool, got string
  ╭▸ main.ocelot-script:1:21
  │
1 │ let enabled: bool = "yes";
  ╰╴                    ━━━━━ initializer has the wrong type
at main.ocelot-script:1:21
```

## Example: bindings are unavailable before initialization

main.ocelot-script:

```ocelot
println(name);
let name = "later";
```

### Error

```text
error: unresolved identifier `name`
  ╭▸ main.ocelot-script:1:9
  │
1 │ println(name);
  ╰╴        ━━━━ not found
at main.ocelot-script:1:9
```
