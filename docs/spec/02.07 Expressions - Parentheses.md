# How are expressions grouped?

Write `(expression)` to create an explicit grouping boundary. Parentheses preserve
the expression's type, result, effects, and early-return behavior. They do not
introduce a scope or discard a value. Nested and redundant groups are valid and
retained by the formatter. Empty `()` is not a value literal: use `{}` for unit;
`()` remains valid in type annotations and empty call parameter/argument lists.
[Expression comment restrictions](<01.01 Lexical structure - Comments.md>) also
apply inside groups; unsupported comments are rejected rather than discarded.

## Example: groups preserve values and direct calls

main.ocelot-script:

```ocelot
fun identity(name: string) -> string {
    (name)
}

let name = ((identity(name: "Ada")));
(core::println)(value: (name));
assert_eq(expected: {}, actual: ({}));
```

### Output

```text
Ada
```

# Do operators have precedence?

No. Different operators at the same expression level require parentheses,
including prefix `not`. Write `(not a) == b` or `not (a == b)`; `not a == b` is
an error. Write `(a == b) and c` or `a == (b and c)`; `a == b and c` is an error.
Similarly, choose `(a and b) or c` or `a and (b or c)` explicitly.

Repeated `not` and chains of only `and` or only `or` are allowed. Boolean chains
evaluate left to right. [Equality](<02.06 Expressions - Equality.md>) remains
non-chainable even when the same comparison operator is repeated.

Calls are operands, not operators: `not ready()` and `ready() and enabled` are
valid. Arguments, block bodies, conditions, and template interpolations contain
their own expressions. The mixing rule does not inspect operators inside those
syntax boundaries. Grouping a function identifier permits a direct call; it does
not turn functions into first-class values.

## Example: explicit groups combine operators without an implicit ordering

main.ocelot-script:

```ocelot
let name = "Ada";
let enabled = true;
println((name == "Ada") and enabled);
println(not (name == "Grace"));
println((not enabled) or (true and true));
println((true == false) == false);
println((false and true) or true);
println(false and (true or true));
```

### Output

```text
true
true
true
true
true
false
```
