# How are source files executed?

`ocelot <source-file>` loads the module tree rooted at the entry file's directory
and then executes that file according to its extension:

| Entry file | Execution |
| --- | --- |
| `.ocelot-script` | Run top-level statements in source order; no `main` is required. |
| `.ocelot` | Call the file's module-local, zero-argument `main()`. |

Normal execution skips [test bodies](./15.01%20Declarations%20-%20Test%20items.md).
See [file modules](./25.01%20Modules%20-%20File%20modules.md) for module naming and discovery.

# In what order do script statements run?

Statements execute in source order.

## Example: a script preserves statement order

main.ocelot-script:

```ocelot
println("first");
println("second");
```

### Output

```text
first
second
```

# How does a module run directly without top-level statements?

Running a `.ocelot` file directly resolves the module defined by that file and calls its `main()` function.
The `main()` function is not a special declaration form.
It is just the conventional module entrypoint name used for direct module execution.
The entrypoint must have no parameters. Ordinary functions, including functions named `main` called explicitly, may have parameters.

## Example: a module can define a `main()` entrypoint

main.ocelot:

```ocelot
fun main() {
    helper::greet();
}
```

helper.ocelot:

```ocelot
fun greet() {
    println("hello");
}
```

### Output

```text
hello
```

# What happens when a directly executed module does not define `main()`?

Direct module execution requires a module-local `main()` function.
If it is missing, startup fails with a dedicated error instead of silently doing nothing.

## Example: a module without `main()` cannot run directly

main.ocelot:

```ocelot
fun helper() {}
```

### Error

```text
module `main` does not define a `main()` entrypoint
```

# What happens when a module file contains a top-level statement?

Module files reject ordinary top-level statements because that syntax is reserved for `.ocelot-script` files.

## Example: a module file cannot contain a top-level statement

main.ocelot:

```ocelot
println("hello");
fun main() {}
```

### Error

```text
error: top-level statements are only allowed in `.ocelot-script` files
  ╭▸ main.ocelot:1:1
  │
1 │ println("hello");
  ╰╴━━━━━━━━━━━━━━━━━ move this statement into `main()` or rename the file to `.ocelot-script`
at main.ocelot:1:1
```
