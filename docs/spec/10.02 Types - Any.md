# What is `any`?

`any` is a special escape-hatch type used by compiler-provided native functions.
It allows functions such as `println` and `assert_eq` to accept different argument types.

- `any` is a real type name
- `any` may only appear in native function signatures
- user-defined functions must not use `any` in parameter types
- ordinary expressions do not infer to `any`
- calls to native functions typed with `any` may pass any currently resolvable argument type

The native implementation may restrict accepted runtime values; see [println](./30.01%20Standard%20library%20-%20println.md).

# What happens when user code tries to use `any` directly?

User-defined functions must not expose `any` in their own signatures.

## Example: user-defined functions cannot declare `any` parameters

main.ocelot-script:

```ocelot
fun log(value: any) {}
```

### Error

```text
error: `any` may only be used in native function signatures
  ╭▸ main.ocelot-script:1:16
  │
1 │ fun log(value: any) {}
  ╰╴               ━━━ `any` is only allowed here for native functions
at main.ocelot-script:1:16
```
