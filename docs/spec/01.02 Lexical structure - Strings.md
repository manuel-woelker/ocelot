# How are strings written?

String literals are enclosed in double quotes and produce `string` values.
A plain string literal must close before the end of the line or file. Comment delimiters
inside strings are text.

Strings containing `${...}` use [template interpolation](./02.03%20Expressions%20-%20Template%20strings.md).
For the distinction between printed strings and quoted eval results, see
[embedded evaluation](./28.03%20Runtime%20behavior%20-%20Embedded%20eval.md).

# What happens when a string literal is not closed?

An unterminated string literal is a lexer error.

## Example: unterminated strings are rejected

main.ocelot-script:

```ocelot
println("hello);
```

### Error

```text
error: unterminated string literal
  ╭▸ main.ocelot-script:1:9
  │
1 │ println("hello);
  ╰╴        ━━━━━━━━ string is missing a closing quote
at main.ocelot-script:1:9
```
