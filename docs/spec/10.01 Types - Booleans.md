# What is the `bool` primitive type?

`bool` is the primitive type for truth values.
Its two values are written directly as the literals `true` and `false`.

# What rules should readers assume first?

For the first version of boolean support:

- `bool` is a primitive type
- `true` and `false` are boolean literals
- booleans are distinct from strings
- `not` is the first boolean operator

This keeps the current slice focused on literal values and one basic operator without pulling in control flow or binary boolean precedence.

# What boolean operator exists today?

The first boolean operator is prefix negation, written as `not`.
It takes one boolean operand and produces the opposite boolean value.

## Example: `not false` produces `true`

main.ocelot-script:

```ocelot
println(not false);
```

### Output

```text
true
```

# What does a boolean literal look like?

A boolean literal is written directly in source as either `true` or `false`.

## Example: `true` is a boolean literal

main.ocelot-script:

```ocelot
println(true);
```

### Output

```text
true
```

## Example: `false` is a boolean literal

main.ocelot-script:

```ocelot
println(false);
```

### Output

```text
false
```
