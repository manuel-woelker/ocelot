# What values have type `bool`?

`bool` has two literal values, `true` and `false`, distinct from strings.
See [prefix negation](./02.02%20Expressions%20-%20Prefix%20negation.md) for the `not` operator and
[function calls](./02.01%20Expressions%20-%20Function%20calls.md) for argument type checking.

## Example: boolean literals have two values

main.ocelot-script:

```ocelot
println(true);
println(false);
```

### Output

```text
true
false
```
