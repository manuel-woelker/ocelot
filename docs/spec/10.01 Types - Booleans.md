# What is the `bool` primitive type?

`bool` is the primitive type for truth values.
Its two values are written directly as the literals `true` and `false`.

# What rules should readers assume first?

For the first version of `bool` support:

- `bool` is a primitive type
- `true` and `false` are `bool` literals
- `bool` values are distinct from strings
- `not` is the first `bool` operator

This keeps the current slice focused on literal values and one basic operator without pulling in control flow or binary boolean precedence.

# What `bool` operator exists today?

The first `bool` operator is prefix negation, written as `not`.
It takes one `bool` operand and produces the opposite `bool` value.

## Example: `not false` produces `true`

main.ocelot-script:

```ocelot
println(not false);
```

### Output

```text
true
```

# What does a `bool` literal look like?

A `bool` literal is written directly in source as either `true` or `false`.

## Example: `true` is a `bool` literal

main.ocelot-script:

```ocelot
println(true);
```

### Output

```text
true
```

## Example: `false` is a `bool` literal

main.ocelot-script:

```ocelot
println(false);
```

### Output

```text
false
```
