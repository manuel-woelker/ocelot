# What is a template string expression?

A template string expression is a quoted string that may embed ordinary expressions using `${` and `}`.
The literal text and embedded expressions are evaluated in source order to produce one runtime string.

For the first version of the feature:

- interpolation is available inside ordinary expression-position strings
- the body of `${...}` is parsed as a normal expression
- each interpolation is evaluated at runtime from left to right
- interpolated values use the language's display rendering
- test-item names do not allow interpolation

# What does a template string look like?

## Example: template strings can interpolate local values

main.ocelot-script:

```ocelot
fun greet(name: string) {
    println("Hello ${name}!");
}

greet("Ada");
```

### Output

```text
Hello Ada!
```

## Example: template strings can interpolate arbitrary expressions

main.ocelot-script:

```ocelot
fun greet(name: string) {
    println("${name} ${not false}");
}

greet("Ada");
```

### Output

```text
Ada true
```

## Example: template strings can nest inside interpolations

main.ocelot-script:

```ocelot
fun greet(name: string) {
    println("${"Hello ${name}!"}");
}

greet("Ada");
```

### Output

```text
Hello Ada!
```

# What happens when a template interpolation is empty?

The parser should reject `${}` because there is no expression to evaluate.

## Example: empty template interpolations are rejected

main.ocelot-script:

```ocelot
println("hello ${}");
```

### Error

```text
error: expected expression inside template interpolation
  ╭▸ main.ocelot-script:1:18
  │
1 │ println("hello ${}");
  ╰╴                 ━ expression expected here
at main.ocelot-script:1:18
```
