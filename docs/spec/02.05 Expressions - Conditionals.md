# What does an if expression produce?

`if condition { ... } else { ... }` evaluates a boolean condition once, then
evaluates only the selected branch. Each branch uses [block results](./02.04%20Expressions%20-%20Blocks.md).
Branch values must have matching types. A branch that always returns from the
enclosing function is compatible with the other branch's type; when both branches
return, the conditional cannot fall through either. Conditions that themselves
return propagate that return before either branch executes.

Braces are required for branches. `else if` chains another conditional. `if` and
`else` are reserved keywords. Conditionals work in all existing expression positions,
including call arguments, templates, function tails, and return expressions.

## Example: conditional results become function results and call arguments

main.ocelot-script:

```ocelot
fun greeting(name: string, excited: bool) -> string {
    if excited {
        "Hello ${name}!"
    } else {
        "Hello ${name}."
    }
}

println(greeting(name: "Ada", excited: true));
println(greeting(name: "Grace", excited: false));
```

### Output

```text
Hello Ada!
Hello Grace.
```

# How are expressions used as statements?

Any expression can be followed by `;` to discard its value. This includes
conditionals, calls, literals, and blocks. Branch types must still agree even
when the resulting value is discarded. A conditional in statement position needs
its semicolon; as a block's tail expression, it keeps its value without one.

Omitting `else` supplies an implicit unit branch. The then branch must therefore
produce unit or always return. To discard a then-branch result, put its semicolon
inside the block; a semicolon after the entire conditional does not change branch types.

## Example: a conditional runs for its effects as an expression statement

main.ocelot-script:

```ocelot
if true {
    println("selected");
};
if false {
    assert(false);
} else {
    println("else selected");
};
if true {
    "discarded"
} else {
    "also discarded"
};
println("after");
```

### Output

```text
selected
else selected
after
```

# How does else if select a value?

Each condition is evaluated only when all earlier conditions were false. The
entire chain must have compatible branch results, including an implicit unit
branch if the last else is omitted.

## Example: else if supplies an expression value

eval:

```ocelot
if false { "first" } else if true { "second" } else { "third" }
```

### Eval result

```text
"second"
```

# How are returns and static checks handled across branches?

Explicit returns exit the enclosing function; branch results complete the
conditional normally. Both branches are statically checked and contribute effects,
even when the condition is a literal. A single returning branch without else
does not establish that all paths return. No constant-condition pruning is used
for result checking.

## Example: returning and value-producing branches share the declared result type

main.ocelot-script:

```ocelot
fun choose(flag: bool) -> string {
    if flag {
        return "early";
    } else {
        "tail"
    }
}

println(choose(flag: true));
println(choose(flag: false));
```

### Output

```text
early
tail
```

# How are invalid conditionals reported?

Condition types, branch compatibility, and incomplete result paths are checked
before execution. Diagnostics point to the condition or incompatible branch result.

## Example: conditions require boolean values

main.ocelot-script:

```ocelot
if "truthy" {};
```

### Error

```text

  ╭▸ main.ocelot-script:1:4
```

## Example: discarded conditionals still require matching branch results

main.ocelot-script:

```ocelot
if true {
    true
} else {
    "no"
};
```
