# What is an executable `ocelot` file?

An executable `ocelot` file runs as a script.
When a file is executed, its top-level statements run in source order without requiring a surrounding `main` function.

# What rules should readers assume first?

For the first version of the spec:

- an executable program is a single `.ocelot` source file
- top-level statements execute in source order
- observable output is produced by effects such as `println()`

More detailed rules about modules, imports, and multi-file execution can be added later.

# What does the smallest executable program look like?

The smallest useful executable program is a file containing one top-level output statement.

## Example: a script can print one line

```ocelot
println("hello");
```

### Output

```text
hello
```

# How does source order affect output?

Top-level statements are evaluated in order.
If two output statements appear one after the other, their lines appear in the same order.

## Example: a script preserves statement order

```ocelot
println("first");
println("second");
```

### Output

```text
first
second
```
