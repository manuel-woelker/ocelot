# What is prefix negation?

Prefix negation is the expression form that inverts one boolean value.
In `ocelot`, it is written with the keyword `not`.

# What rules should readers assume first?

For the first version of prefix negation:

- the operator spelling is `not`
- the operand must be a boolean expression
- the result is a boolean value
- prefix negation may be nested
- function calls bind tighter than `not`

This keeps the rule set small and predictable.

# What does prefix negation look like?

## Example: `not false` evaluates to `true`

main.ocelot-script:

```ocelot
println(not false);
```

### Output

```text
true
```

## Example: nested `not` expressions are allowed

main.ocelot-script:

```ocelot
println(not not false);
```

### Output

```text
false
```
