# What is prefix negation?

Prefix negation is the expression form that inverts one `bool` value.
In `ocelot`, it is written with the keyword `not`.

- the operator spelling is `not`
- the operand must be a `bool` expression
- the result is a `bool` value
- prefix negation may be nested
- calls are operands, so `not enabled()` is valid
- different operators require [parentheses](<02.07 Expressions - Parentheses.md>);
  write `not (a == b)` or `(not a) == b` to choose the intended structure

## Example: `not false` evaluates to `true`

main.ocelot-script:

```ocelot
println(not false);
```

### Output

```text
true
```

## Example: nested `not` expressions are allowed

main.ocelot-script:

```ocelot
println(not not false);
```

### Output

```text
false
```
