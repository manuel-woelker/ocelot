# Where is project documentation?

- [Overview](OVERVIEW.md): implemented language features and workspace organization.
- [Language specification](spec/README.md): language rules and executable examples.
- [Testing](TESTING.md): test organization, platform boundaries, and verification.
- [Planning](PLANS.md): plan format and completion workflow.
- [Decision records](decisions/README.md): significant choices, rationale,
  consequences, and alternatives; follow [DR-000](<decisions/DR-000 Record decisions in the repository.md>).
- [Development learnings](learnings/README.md): dated findings with context,
  evidence, references, and a copyable template. Consult related findings and
  record reusable discoveries alongside the work that establishes them.
- [Release process](RELEASE.md): packaging and release instructions.

Keep documentation current with the changes it describes. Findings belong in
learnings, language behavior in the spec, implementation tasks in plans, and
significant choices and their rationale in decision records.
